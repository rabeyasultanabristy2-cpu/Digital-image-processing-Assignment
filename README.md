# Digital-image-processing-Assignment
This project demonstrates basic image processing operations using Python, OpenCV, and Matplotlib.

Objective
To perform basic image processing operations on an image using Python.

Operations Performed
Read the image
Display the image
Print the image dimensions
Print the pixel value at (100,100)
Convert the image to grayscale
Print the grayscale image dimensions
Display the grayscale image
Resize the image to 300 × 300
Crop a portion of the image
Save the grayscale image as gray_output.jpg
Technologies Used
Python
OpenCV
Matplotlib

Original Image


Grayscale Image


Resized Image


Cropped Image


Output Files

gray_output.jpg - Grayscale image

Cropped_output.png - Cropped image
